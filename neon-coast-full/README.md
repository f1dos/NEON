# Neon Coast -> APK

Загрузите ВСЁ содержимое этого архива в корень репозитория на GitHub
(включая скрытую папку .github, если её видно).
Если папку .github загрузить не получилось: Add file -> Create new file,
имя .github/workflows/build.yml, вставьте текст из build.yml.txt.

Потом: Actions -> Build APK -> Run workflow -> через 5-10 минут Artifacts -> neon-coast-apk.
Если упало — причина написана в красной плашке Annotations.
